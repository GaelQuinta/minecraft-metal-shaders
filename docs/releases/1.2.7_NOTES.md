# 1.2.7-alpha — settings and light-boundary maintenance

Minecraft 26.3, Fabric, Apple Silicon, macOS 15+. No separate Sodium installation.

## Changes

- Fix twelve percentage sliders that wrote values 100× too small (#21). Cloud-shadow strength 80% writes `0.8`;
  dynamic-light strength 400% writes `4`. The non-unit forest-air and wet-darkening bases are preserved.
- Reject invalid live god-ray resolution overrides, including the `0.005` left by an old 50% setting. Use the preset
  resolution instead of allocating a light buffer with only a handful of rows.
- Repair foreground/background discontinuities in both god-ray upsamplers: use same-depth observations when available,
  and avoid extending an occluding leaf's signed light correction onto unseen background/sky (#19). The common smooth
  surface path retains its four-depth gather and one filtered fetch; only discontinuities pay the four outer probes.
- Atmosphere → **Opposite sunset**: reduce red/pink opposite the sun, preserving brightness. Default 100% retains
  the released look. Sky, reflected sky and atmospheric colours follow it; the sun-facing sky is preserved (#18).
- Blocky cloud drift uses a continuous real-time clock instead of re-reading server-corrected game ticks each frame.
  Freeze and wind-speed controls apply to it, and activation/mode changes reset its clock (#22).
- Reuse the CPU atmosphere's scratch arrays per result, and precompute its fixed ambient sampling geometry. Default
  lighting results remain bitwise identical; the routine allocates 288 fewer temporary bytes per call. This small local
  reduction does not eliminate Minecraft's normal heap/GC cycle (#14).

## Updating settings

Set any affected sliders again, or reset them, after updating. Previously saved values may also have been intentional
hand edits; their provenance cannot be inferred reliably. This version fixes new saves and protects VL allocation from
invalid live resolution, but does not silently multiply or rewrite ambiguous saved values.

Affected controls: cave air glow, held-light strength, cloud-shadow strength, sharpening, HDR scene/UI brightness,
god-ray/cloud resolution, waterfalls, torch caustics, drying speed, and minimum dynamic resolution.

## Validation

- Java/native build, runtime MSL pipeline compilation, own terrain/PBR variants, translations.
- 11,388 percentage positions over four presets; per-option file save, reload, reset and physical-base checks.
- Eight tiny real-GPU fixtures execute both production upsamplers. They include depth discontinuities, signed light,
  very close geometry, constant transmission and dynamic-resolution subrect bounds. The 1.2.6 baseline fails the
  foreground-to-background borrowing assertion; the new code passes.
- 1,024 CPU sun/weather fixtures (188,416 output bytes) match 1.2.6 bit for bit at defaults. The optional sunset control
  separately preserves luminance and the sun-facing sky.
- An isolated full-resolution post-pass stress test with mismatched-depth inputs priced the first broad edge search at
  about +1.1 ms. Limiting recovery to four probes reduced that to about +0.2 ms. These are synthetic pass costs, not a
  measured game-wide FPS gain.

Reproduction tools: `tools/shade/regression127/`. Game comparisons and final smoke checks are recorded in the development
log; absolute FPS depend on scene, resolution, thermal state and other applications.

## Remaining reports and scope

- #19's exact M5 Pro video is not reproduced on the M4. Three recorded local holds had nearly unchanged global temporal
  noise. The targeted depth/settings fixes are verified; the full report stays open for settings and confirmation.
- #16's long-session M5 driver assertion remains open for a full `.ips`, logs and an official-build reproduction. This
  release makes no native command-buffer lifetime change and does not claim to fix that crash.
- Metal 4 migration (#20), experimental ProMotion scheduling (#11), interactive/waving foliage (#18), and the RT bundle
  (#22) are not integrated in this maintenance release. They need separate measurements and integration work.
- Thanks to the reporters and contributors for the reproducible settings diagnosis, measurements, and experimental
  source/notes. The #22 archive was studied for techniques; its patch was not copied wholesale over the current code.
