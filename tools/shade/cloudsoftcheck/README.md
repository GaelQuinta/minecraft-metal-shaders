# Soften cloud fringes and lighten fair-weather interiors

After `:metal:build`, run `JAVA_HOME=/path/to/jdk25 GRADLE_USER_HOME=/path/to/cache python3 tools/shade/cloudsoftcheck/run.py /tmp/cloudsoftcheck` on a Mac with GPU access. Produces four offscreen production cloud previews. Inspect noon, afternoon, sunset and storm before/after renders; these fixtures are not in-game screenshots. No game is launched.
