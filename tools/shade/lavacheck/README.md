# Lava regression

After building, run `JAVA_HOME=/path/to/jdk25 GRADLE_USER_HOME=/path/to/cache python3 tools/shade/lavacheck/run.py /tmp/lavacheck` with GPU access. Checks actual lava material functions, empty and valid atlas rectangles, heat-response monotonicity and finite emission. Compiles all 22 terrain libraries including PBR, Nether and water. This is a dedicated lighting treatment of the animated pack texture, not fluid simulation or a replacement geometry/texture system. No game is launched.
